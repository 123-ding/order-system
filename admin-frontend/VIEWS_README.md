# 订餐系统管理后台 - Admin Frontend

## 📁 项目结构

```
admin-frontend/
├── src/
│   ├── views/
│   │   ├── login/
│   │   │   └── index.vue          # 登录页面
│   │   ├── dashboard/
│   │   │   └── index.vue          # 仪表盘
│   │   ├── dishes/
│   │   │   └── index.vue          # 菜品管理
│   │   ├── categories/
│   │   │   └── index.vue          # 分类管理
│   │   ├── orders/
│   │   │   └── index.vue          # 订单管理
│   │   ├── reviews/
│   │   │   └── index.vue          # 评价管理
│   │   ├── users/
│   │   │   └── index.vue          # 用户管理
│   │   ├── settings/
│   │   │   └── index.vue          # 系统设置
│   │   ├── Layout.vue             # 主布局
│   │   └── NotFound.vue           # 404页面
│   ├── api/
│   │   ├── request.js             # Axios封装
│   │   └── admin.js               # API接口
│   ├── router/
│   │   └── index.js               # 路由配置
│   ├── store/
│   │   └── index.js               # Pinia状态管理
│   └── main.js                    # 入口文件
├── package.json
└── vite.config.js
```
