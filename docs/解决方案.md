### 1.2 核心设计原则

1. **协议适配插件化**：每种通信协议封装为独立适配器，实现 `IDeviceAdapter` 接口，系统启动时按配置动态加载；
2. **统一数据模型**：所有适配器输出统一的内部数据模型（`DeviceData`），上层业务逻辑不感知底层协议差异；
3. **事件驱动**：使用内部消息总线（EventEmitter / Redis Pub-Sub），设备数据、状态变更、告警均以事件方式传递；
4. **安全默认**：所有外部连接默认启用 TLS，API 默认需要认证。

## 3. 协议适配层设计

### 3.1 适配器接口

```typescript
interface IDeviceAdapter {
  // 连接到设备
  connect(config: ConnectionConfig): Promise<void>;
  // 断开连接
  disconnect(): Promise<void>;
  // 下发指令
  sendCommand(command: DeviceCommand): Promise<CommandResult>;
  // 订阅数据事件
  on(event: 'data' | 'status' | 'error', listener: Function): void;
  // 健康检查
  healthCheck(): Promise<boolean>;
}

interface ConnectionConfig {
  protocol: ProtocolType;    // 协议类型（枚举）
  host?: string;             // IP 地址
  port?: number;             // 端口
  serialPort?: string;       // 串口号
  baudRate?: number;         // 波特率
  mqttBroker?: string;       // MQTT Broker URL
  topic?: string;            // MQTT Topic
  username?: string;
  password?: string;
  tlsCert?: string;          // TLS 客户端证书
}
```

### 3.2 支持的协议类型

```typescript
enum ProtocolType {
  MAVLINK_V1 = 'mavlink_v1',
  MAVLINK_V2 = 'mavlink_v2',
  DJI_SDK    = 'dji_sdk',
  TCP_CUSTOM = 'tcp_custom',
  UDP_CUSTOM = 'udp_custom',
  SERIAL_RS232 = 'serial_rs232',
  SERIAL_RS485 = 'serial_rs485',
  MQTT       = 'mqtt',
  WEBSOCKET  = 'websocket',
  HTTP_REST  = 'http_rest',
  ONVIF      = 'onvif',
  ADS_B      = 'ads_b',
}
```

### 3.3 数据标准化模型

```typescript
interface DeviceData {
  deviceId: string;          // 设备 ID
  deviceType: DeviceType;    // 设备类型（UAV/DETECT/SENSE/COUNTER）
  timestamp: number;         // 数据时间戳（ms）
  status: DeviceStatus;      // 在线/离线/告警
  position?: {               // 位置（适用于无人机）
    lat: number;
    lng: number;
    altitude: number;
  };
  telemetry?: Record<string, any>;  // 遥测数据
  rawData?: Buffer;          // 原始报文（用于调试）
}
```

### 5.2 devices 表结构示例

```sql
CREATE TABLE devices (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,
  name          VARCHAR(100) NOT NULL UNIQUE,
  brand         VARCHAR(50),
  model         VARCHAR(50),
  device_type   ENUM('uav','detection','sensing','countermeasure') NOT NULL,
  group_id      BIGINT,
  region        VARCHAR(100),
  status        ENUM('online','offline','alarm','disabled') DEFAULT 'offline',
  last_seen_at  DATETIME,
  created_by    BIGINT,
  created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE TABLE device_connections (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,
  device_id     BIGINT NOT NULL REFERENCES devices(id),
  protocol      VARCHAR(30) NOT NULL,
  host          VARCHAR(255),
  port          INT,
  serial_port   VARCHAR(50),
  baud_rate     INT,
  extra_config  TEXT,          -- JSON，存储协议特定参数（加密）
  created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 6. 安全方案

### 6.1 认证与授权

```
用户登录
  → 用户名/密码验证（bcrypt 哈希）
  → (可选) TOTP 验证码验证
  → 生成 JWT Access Token（8h）+ Refresh Token（7d）
  → 前端存储于 httpOnly Cookie（防 XSS）

API 调用
  → 请求携带 JWT Token
  → Nginx / 中间件校验签名和有效期
  → 校验用户角色/权限（RBAC）
  → 允许/拒绝请求
```

### 6.2 设备通信安全

- 对于支持 TLS 的设备连接，强制启用双向 TLS 认证；
- 设备密钥/密码在数据库中使用 AES-256-GCM 加密存储；
- 反制指令下发需要二次确认（操作员确认 + 系统内部签名验签）。
