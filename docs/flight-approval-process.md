# 低空飞行活动审批与放飞流程

本文档描述石狮市低空经济服务平台的飞行活动审批流程及放飞审批流程。

---

## 一、飞行活动审批 + 放飞审批 总流程

```mermaid
flowchart TD
    A([用户提交飞行活动申请]) --> B{飞行活动类型判断}
    B --> C[一般飞行活动]
    B --> D[长期飞行活动]
    B --> E[紧急飞行活动]
    B --> F[场内飞行活动]

    C --> G[飞行活动审批流程]
    D --> G
    E --> G
    F --> G

    G --> H{审批节点1 - 初审<br/>审批部门：石狮市交港局 运输安全股<br/>职责：受理、材料完整性校验、合规初筛、风险标注<br/>输出：通过/驳回/补正}
    H -->|不通过| R1([审批驳回，通知申请人])
    H -->|通过| I{审批节点2 - 复审<br/>审批部门：石狮市交港局 运输安全股<br/>职责：冲突审查、敏感空域复核、审批条件设置、归档留痕<br/>输出：批准（含条件）/不批准}
    I -->|不通过| R2([审批驳回，通知申请人])
    I -->|通过| J([飞行活动审批通过])

    J --> K[计划起飞1小时前<br/>提交放飞申请]
    K --> L{放飞审批节点 - 审批<br/>审批部门：石狮市公安局 治安管理大队<br/>职责：核对已批及条件满足、起飞前1小时信息确认、临时管制与空域动态检查、最终放飞确认、记录留痕<br/>输出：允许起飞/不得起飞}
    L -->|不通过| R3([放飞申请驳回，通知申请人])
    L -->|通过| M([放飞申请通过，允许起飞])
    L -->|军方空域/临时管制| MIL[军队/空中交通管理机构确认/对接<br/>适用：涉及军方管控空域、临时管制或特定类型任务<br/>操作：发起军方确认或同步，接收确认结果<br/>待与军方接口规范确认]
    MIL -->|军方确认通过| M
    MIL -->|军方不予放行| R3

    style A fill:#4CAF50,color:#fff
    style J fill:#2196F3,color:#fff
    style M fill:#4CAF50,color:#fff
    style R1 fill:#f44336,color:#fff
    style R2 fill:#f44336,color:#fff
    style R3 fill:#f44336,color:#fff
    style MIL fill:#FF9800,color:#fff
```

> **军队对接分支说明**
>
> 当放飞审批节点（石狮市公安局 治安管理大队）在审批过程中发现飞行任务涉及以下情形之一时，需触发"军队/空中交通管理机构确认/对接"分支：
> - 飞行区域涉及**军方管控空域**或**临时限制/禁止空域**
> - 飞行计划处于**临时管制**期间
> - 任务性质属于**特定类型**（如大型活动保障、特种飞行等）需军方协调确认
>
> ⚠️ **待与军方接口规范确认**：军方确认的具体流程、接口标准及数据格式，需与军队空管部门协商后进一步明确。

## 三、放飞审批详细流程

```mermaid
flowchart TD
    subgraph 前置条件
        A([飞行活动已获批准]) --> B[计划起飞1小时前]
    end

    B --> C[提交放飞申请<br/>报告预计起飞时刻和准备情况]

    subgraph 放飞审批阶段["放飞审批阶段（石狮市公安局 治安管理大队）"]
        C --> D{放飞审批节点 - 确认<br/>审批部门：石狮市公安局 治安管理大队<br/>职责：核对已批及条件满足、起飞前1小时信息确认、临时管制与空域动态检查、最终放飞确认、记录留痕<br/>输出：允许起飞/不得起飞}
        D -->|确认通过| E([允许起飞])
        D -->|不通过| F([放飞申请驳回<br/>不得起飞])
        D -->|军方空域/临时管制| MIL[军队/空中交通管理机构确认/对接<br/>适用：涉及军方管控空域、临时管制或特定类型任务<br/>操作：发起军方确认或同步，接收确认结果<br/>待与军方接口规范确认]
        MIL -->|军方确认通过| E
        MIL -->|军方不予放行| F
    end

    style A fill:#2196F3,color:#fff
    style E fill:#4CAF50,color:#fff
    style F fill:#f44336,color:#fff
    style MIL fill:#FF9800,color:#fff
```

> **军队对接分支说明（放飞审批）**
>
> 当放飞审批节点在审批过程中发现飞行任务涉及军方管控空域、临时管制或特定类型任务时，审批人员需触发"军队/空中交通管理机构确认/对接"流程：
> 1. 由治安管理大队值班席位或系统自动发起军方确认请求；
> 2. 军方反馈"确认通过"后，方可最终允许起飞；
> 3. 军方反馈"不予放行"时，作驳回处理并通知申请人。
>
> ⚠️ **待与军方接口规范确认**：具体确认流程、接口标准及数据格式需与军队空管部门协商后进一步明确。
