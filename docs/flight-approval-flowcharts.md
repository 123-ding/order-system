## 四、纵向上报流程图

> 石狮市权限范围内由交港局直接审批；跨区域/特殊空域需经石狮初审后逐级上报至泉州、福建、UOM。

```mermaid
flowchart TD
    A([申请人提交飞行活动申请]) --> B[石狮市平台受理]

    B --> C{飞行活动类型与空域判断}

    C -->|石狮市权限范围内| D[石狮市交港局 运输安全股<br/>审批节点1 + 审批节点2]
    C -->|跨区域/特殊空域/大型活动| SS1{石狮初审<br/>交港局 运输安全股}
    SS1 -. 职责说明 .-> SS1_duty[【石狮初审职责】<br/>· 材料完整性校验<br/>· 合规初筛<br/>· 风险标注<br/>· 上报建议<br/>输出：同意上报 / 退回补正]
    SS1 -->|同意上报| E[上报泉州市平台]
    SS1 -->|退回补正| B

    D -->|审批通过| F[审批结果同步上报<br/>泉州 → 福建 → UOM]
    D -->|审批驳回| R1([驳回通知申请人])

    E --> G{泉州市平台审批}
    G -->|需省级协调| H[上报福建省平台]
    G -->|泉州市权限内| I[泉州市审批]

    H --> J{福建省平台审批}
    J -->|需国家级协调| K[上报UOM平台<br/>空军/民航协调]
    J -->|省级权限内| L[福建省审批]

    K --> M[UOM协调空管机构]
    M --> N([审批结果逐级下达])

    L --> N
    I --> N
    F --> O([审批通过])
    N --> O

    O --> P[计划起飞1小时前<br/>提交放飞申请]
    P --> Q{放飞审批<br/>公安局 治安管理大队}
    Q -->|确认| R([允许起飞<br/>起飞信息同步上报UOM])
    Q -->|不通过| S([不得起飞])

    style A fill:#4CAF50,color:#fff
    style O fill:#2196F3,color:#fff
    style R fill:#4CAF50,color:#fff
    style R1 fill:#f44336,color:#fff
    style S fill:#f44336,color:#fff
    style SS1_duty fill:#fff9c4,stroke:#f9a825
```

## 审批节点职责汇总

| 审批节点 | 审批部门 | 完整职责 |
|---------|---------|---------|
| **审批节点1-初审** | 石狮市交港局 运输安全股 | 受理申请、材料完整性校验、合规初筛、风险标注 |
| **审批节点2-复审** | 石狮市交港局 运输安全股 | 冲突审查、敏感空域复核、审批条件设置、归档留痕 |
| **石狮初审**（跨区域上报前） | 石狮市交港局 运输安全股 | 材料完整性校验、合规初筛、风险标注、上报建议 |
| **放飞审批节点** | 石狮市公安局 治安管理大队 | 核对已批条件满足、起飞前1小时信息确认、临时管制与空域动态检查、最终放飞确认、记录留痕 |
| **军方对接**（备案/审核） | 解放军相关部门 | 备案：记录回执/编号/时间；特殊类型审核：空域放行确认 |
