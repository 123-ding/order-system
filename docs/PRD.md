## 1. 产品概述

### 1.1 背景

随着国内沿海贸易和国际航运业务快速增长，传统的海上物流管理模式效率低下，信息传递滞后，船货双方协调困难。本平台旨在通过数字化手段，提升海上货运全流程管理效率，降低物流成本，增强客户体验。

### 1.2 产品定位

**海上物流配送平台**是一套面向航运企业和货主的一站式海上货运管理系统，支持订单在线下单、船舶调度、货物追踪、运费结算等核心业务流程。

### 1.3 目标用户

- 航运公司运营管理人员
- 货运代理商
- 有海运需求的企业/个人货主

### 1.4 核心价值

- **提效**：线上化订单流程，减少人工沟通成本
- **透明**：实时掌握船舶动态和货物状态
- **可靠**：完整的订单流转记录，便于追溯和对账

## 2. 用户角色

### 2.1 管理员（Admin）

负责平台整体运营管理，拥有最高权限。

**主要职责：**
- 管理所有用户账号（创建、编辑、禁用）
- 管理船舶基础信息
- 管理航线基础信息
- 查看全量订单数据
- 系统配置与维护

### 2.2 调度员（Operator）

负责日常订单处理和船舶调度。

**主要职责：**
- 处理客户订单（确认、调度、跟踪）
- 管理船舶状态和位置信息
- 录入和更新货物信息
- 更新订单运输状态

**权限范围：**
- 可查看和操作所有订单，但不能删除
- 不可管理用户账号
- 不可修改系统基础配置

### 2.3 客户（Customer）

货主或货代，通过平台下单和跟踪货物。

**主要职责：**
- 在线提交运输订单
- 查看自己的订单状态
- 查看关联货物信息
- 取消待处理的订单

**权限范围：**
- 仅能查看和操作自己名下的订单
- 不可访问其他用户数据
- 不可管理船舶和航线

## 3. 核心功能模块

### 3.1 用户认证

| 功能       | 说明 |
|------------|------|
| 账号登录   | 支持用户名+密码登录，返回 JWT Token |
| Token 刷新 | 有效期内可刷新 Token，避免频繁登录 |
| 安全退出   | 服务端使 Token 失效 |
| 密码修改   | 用户可修改自己的登录密码 |

### 3.2 订单管理

**订单状态流转：**

```
待处理(pending)
    ↓ 调度员确认
已确认(confirmed)
    ↓ 开始装货
装货中(loading)
    ↓ 船舶出港
运输中(in_transit)
    ↓ 抵达目的港
已到港(arrived)
    ↓ 货物交付完毕
已完成(completed)

任意状态（已完成除外）→ 已取消(cancelled)
```

| 功能         | 说明 |
|--------------|------|
| 提交订单     | 填写起运港、目的港、货物类型、重量等信息 |
| 订单列表     | 支持多条件筛选：状态、时间范围、港口等 |
| 订单详情     | 查看完整订单信息，包含关联船舶、航线、货物 |
| 状态更新     | 调度员推进订单状态，记录实际起/到港时间 |
| 取消订单     | pending 状态可取消，记录取消原因 |
| 运费计算     | 根据货物重量和航线运费率自动计算运费 |

### 3.3 船舶管理

| 功能           | 说明 |
|----------------|------|
| 船舶档案管理   | 录入船名、类型、注册号、载重、舱容等信息 |
| 状态管理       | 维护船舶当前状态：空闲/使用中/维修中/退役 |
| 位置追踪       | 记录船舶当前所在港口 |
| 可用船舶查询   | 为订单分配时快速筛选可用船舶 |

**船舶类型：**
- `container`：集装箱船
- `bulk_carrier`：散货船
- `tanker`：油轮/化学品船
- `ro_ro`：滚装船

### 3.4 航线管理

| 功能         | 说明 |
|--------------|------|
| 航线档案管理 | 维护航线起止港口、距离、预计天数、运费率 |
| 航线启停     | 支持航线的上架和下架 |
| 运费参考     | 航线运费率作为订单运费计算的参考依据 |

### 3.5 货物管理

| 功能         | 说明 |
|--------------|------|
| 货物录入     | 为订单添加多批货物，记录品名、重量、体积、数量 |
| 特殊属性标记 | 支持标记危险品、温控要求及温度范围 |
| 货物状态追踪 | 待装/已装/运输中/已卸/已交付 |
| 货物编号管理 | 系统自动生成唯一货物编号，便于追踪 |

### 3.6 数据统计（后台）

| 报表             | 说明 |
|------------------|------|
| 订单数量统计     | 按状态、时间段统计订单数量 |
| 运费收入统计     | 按月/季度统计运费收入 |
| 船舶利用率       | 统计各船舶使用率 |
| 航线热度分析     | 按航线统计货运量 |

## 4. 移动端客户端需求

移动端面向**客户**用户，基于 H5/PWA 实现，适配主流手机浏览器。

### 4.1 页面结构

```
底部导航栏：
├── 首页（概览）
├── 下单
├── 订单
└── 我的
```

### 4.2 首页

- 欢迎语，显示用户名
- 待处理订单数量提示
- 快捷入口：新建订单、查询订单
- 常用航线推荐列表

### 4.3 在线下单

**下单流程：**

1. 选择起运港和目的港（支持下拉搜索）
2. 选择货物类型、填写重量/体积
3. 填写预计发运日期
4. 查看预估运费（根据重量×航线运费率计算）
5. 填写备注（特殊要求）
6. 提交订单

**交互要求：**
- 表单字段实时验证
- 必填项标红提示
- 提交后显示订单号和结果提示
- 支持草稿保存

### 4.4 订单列表

- 展示我的全部订单，默认按创建时间倒序
- 顶部状态 Tab 快速筛选：全部 / 待处理 / 进行中 / 已完成
- 每条订单显示：订单号、起止港口、状态标签、创建日期
- 点击进入订单详情

### 4.5 订单详情

- 完整订单信息展示
- 货物明细列表（可展开）
- 订单状态时间轴（展示每个状态节点的时间）
- 操作按钮：取消订单（仅 pending 状态）、联系客服

### 4.6 个人中心

- 显示用户基本信息（头像、用户名、手机号）
- 修改密码入口
- 退出登录

### 4.7 移动端技术要求

- 基于 Vue 3 + Vant UI
- 适配屏幕宽度：320px ~ 428px
- 首屏加载时间 < 3 秒（4G 网络）
- 支持下拉刷新、上拉加载更多
- 支持离线提示

## 5. PC 后台管理系统需求

后台面向**管理员**和**调度员**，在桌面浏览器中使用。

### 5.1 整体布局

```
┌─────────────────────────────────────────────┐
│  顶部导航栏（Logo + 用户信息 + 退出）          │
├─────────┬───────────────────────────────────┤
│         │                                   │
│  左侧   │         主内容区域                  │
│  菜单   │                                   │
│         │                                   │
└─────────┴───────────────────────────────────┘
```

### 5.2 左侧菜单结构

```
├── 首页（Dashboard）
├── 订单管理
│   ├── 订单列表
│   └── 新建订单
├── 船舶管理
│   ├── 船舶列表
│   └── 新增船舶
├── 航线管理
│   ├── 航线列表
│   └── 新增航线
├── 货物管理
├── 用户管理（仅 admin）
└── 数据统计（仅 admin）
```

### 5.3 Dashboard 页面

- 核心数字卡片：总订单数、本月新增订单、在途订单、可用船舶数
- 近30天订单趋势折线图
- 订单状态分布饼图
- 最新订单列表（10条）

### 5.4 订单管理

**订单列表页：**
- 顶部多条件搜索栏（订单号、状态、港口、时间范围、船舶、客户）
- 表格展示：订单号、客户、起止港口、货物类型、运费、状态、创建时间、操作
- 操作按钮：查看详情、编辑状态、取消
- 导出 Excel 功能

**订单详情/编辑页：**
- 基础信息表单（起止港口、货物类型、重量、体积）
- 关联信息（分配船舶、选择航线）
- 状态变更（带确认弹窗，需填写实际起/到港时间）
- 货物明细子表格（支持增删改）

### 5.5 船舶管理

- 表格展示所有船舶：船名、类型、注册号、载重、状态、当前位置
- 搜索：船名、类型、状态
- 操作：新增、编辑、状态变更、删除
- 状态标签颜色区分：绿色（空闲）、橙色（使用中）、黄色（维修）、灰色（退役）

### 5.6 航线管理

- 表格展示所有航线：名称、起止港口、距离、天数、运费率、状态
- 操作：新增、编辑、启用/停用、删除

### 5.7 货物管理

- 可按订单筛选查看货物
- 支持批量更新货物状态
- 危险品/温控货物高亮提示

### 5.8 用户管理（仅 admin）

- 用户列表：用户名、邮箱、手机、角色、状态、注册时间
- 操作：新增、编辑、禁用/启用、重置密码、删除
- 按角色筛选

### 5.9 后台技术要求

- 基于 Vue 3 + Element Plus
- 支持主流浏览器（Chrome、Firefox、Edge 最新版）
- 表格支持列排序
- 所有列表页支持分页（默认每页 20 条）
- 操作类按钮需二次确认弹窗

## 6. 非功能性需求

### 6.1 性能要求

| 指标               | 要求 |
|--------------------|------|
| API 响应时间       | 普通查询 < 500ms，复杂统计 < 2s |
| 并发用户数         | 支持 100 个并发用户正常使用 |
| 移动端首屏时间     | 4G 网络下 < 3s |
| 数据库查询时间     | 单表查询 < 100ms |

### 6.2 安全要求

| 要求             | 说明 |
|------------------|------|
| 密码加密         | 用户密码使用 bcrypt（cost factor ≥ 10）存储 |
| Token 认证       | 所有接口（除登录外）需携带有效 JWT Token |
| 权限控制         | 严格按角色控制接口访问权限，防止越权操作 |
| 输入验证         | 所有用户输入在服务端进行参数校验和 SQL 注入防护 |
| HTTPS            | 生产环境强制 HTTPS |
| 敏感数据保护     | 接口响应中不返回 password_hash 字段 |

### 6.3 可用性要求

- 系统可用性：≥ 99.5%（月度）
- 计划维护窗口：每周日凌晨 02:00 ~ 04:00
- 数据库每日自动备份，备份保留 30 天

### 6.4 兼容性要求

**移动端：**
- iOS Safari 14+
- Android Chrome 90+

**PC 后台：**
- Chrome 100+
- Firefox 100+
- Edge 100+

### 6.5 国际化

- 当前版本：简体中文
- 预留国际化扩展能力（i18n），未来可支持英文

## 7. 数据字典

### 订单状态

| 值           | 中文含义 | 说明 |
|--------------|----------|------|
| `pending`    | 待处理   | 客户提交后，等待调度员确认 |
| `confirmed`  | 已确认   | 调度员确认，分配船舶和航线 |
| `loading`    | 装货中   | 货物正在装船 |
| `in_transit` | 运输中   | 船舶已出港，货物在途 |
| `arrived`    | 已到港   | 船舶抵达目的港 |
| `completed`  | 已完成   | 货物交付，订单关闭 |
| `cancelled`  | 已取消   | 订单取消 |

### 船舶状态

| 值            | 中文含义 |
|---------------|----------|
| `available`   | 空闲可用 |
| `in_use`      | 使用中   |
| `maintenance` | 维修中   |
| `retired`     | 已退役   |

### 船舶类型

| 值             | 中文含义 |
|----------------|----------|
| `container`    | 集装箱船 |
| `bulk_carrier` | 散货船   |
| `tanker`       | 油轮     |
| `ro_ro`        | 滚装船   |

### 货物状态

| 值           | 中文含义 |
|--------------|----------|
| `pending`    | 待装货   |
| `loaded`     | 已装船   |
| `in_transit` | 运输中   |
| `unloaded`   | 已卸货   |
| `delivered`  | 已交付   |

### 用户角色

| 值           | 中文含义 |
|--------------|----------|
| `admin`      | 管理员   |
| `operator`   | 调度员   |
| `customer`   | 客户     |
