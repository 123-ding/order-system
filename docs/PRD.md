# 点菜系统 PRD（产品需求文档）

本文档详细描述了智能点菜系统的产品需求、功能设计和技术实现方案。

## 一、项目概述

### 1.1 项目背景
创建一个完整的智能点菜系统，支持微信公众号形式，包含后台管理和移动端用户界面。

### 1.2 项目目标
- 提供美观易用的后台管理系统，方便管理员管理菜品
- 提供流畅的移动端用户体验，支持微信公众号访问
- 实现微信消息推送功能
- 支持用户评价系统

### 1.3 技术栈
**后端：**
- Node.js 18+
- Express.js 4.x
- MySQL 8.0  
- Redis 6.x
- JWT认证
- 微信公众号SDK

**后台管理前端：**
- Vue 3 (Composition API)
- Element Plus
- Vue Router 4
- Pinia
- Vite

**移动端前端：**
- Vue 3 (Composition API)
- Vant UI 4.x
- Vue Router 4
- Pinia
- Vite
