# 飞行汽车运营平台 - 系统架构设计

## 1. 概述

飞行汽车运营平台是一个综合性的城市空中交通（UAM, Urban Air Mobility）运营管理系统，旨在为飞行汽车的商业化运营提供全面的技术支撑。平台覆盖从乘客出行预订到航班调度、空域管理、实时监控、安全保障的全流程管理。

## 2. 系统定位

### 2.1 目标用户
| 用户角色 | 描述 |
|---------|------|
| **乘客** | 通过移动端 APP/小程序预订飞行汽车出行服务 |
| **飞行员/操作员** | 负责飞行汽车的驾驶或远程操控 |
| **运营管理员** | 负责航班调度、车辆管理、运营监控 |
| **维保人员** | 负责飞行汽车的日常维护和检修 |
| **空域管理员** | 负责空域协调和飞行路线审批 |
| **平台管理员** | 负责系统配置、权限管理、数据分析 |

### 2.2 核心业务场景
- **城市通勤**：高峰时段的快速点对点空中通勤
- **机场接驳**：城市中心到机场的快速空中连接
- **景区观光**：空中旅游观光体验
- **紧急运输**：医疗急救、紧急物资运输
- **VIP 专线**：高端商务出行服务

### 3.2 技术选型

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| **后端服务** | Node.js 18+ / Express.js | 高并发异步处理，适合实时通信场景 |
| **管理后台** | Vue 3 + Element Plus + Vite | 现代化管理界面，组件丰富 |
| **移动端** | Vue 3 + Vant UI + Vite | 移动优先，微信生态集成 |
| **监控大屏** | Vue 3 + ECharts + 高德地图 | 实时数据可视化与地图展示 |
| **数据库** | MySQL 8.0 | 核心业务数据存储 |
| **缓存** | Redis 6.x | 会话、热点数据、排行榜 |
| **消息队列** | RabbitMQ / Redis Stream | 异步任务、事件驱动 |
| **实时通信** | Socket.IO | 实时位置推送、消息通知 |
| **地图服务** | 高德地图 / Mapbox | 2D/3D 地图展示、路径规划 |
| **对象存储** | 阿里云 OSS / MinIO | 图片、文档、日志文件 |
| **容器化** | Docker + Kubernetes | 微服务部署与编排 |
| **监控** | Prometheus + Grafana | 系统监控与告警 |

## 4. 核心模块设计

### 4.1 用户服务 (User Service)
```
功能：
├── 乘客注册/登录（手机号、微信、人脸识别）
├── 飞行员管理（资质验证、排班管理）
├── 角色权限管理（RBAC 模型）
├── 用户画像与偏好管理
└── 实名认证与安全审核
```

### 4.2 订单服务 (Order Service)
```
功能：
├── 行程预订（即时/预约）
├── 智能定价（动态定价算法）
├── 订单状态机管理
├── 取消/退款处理
├── 订单评价系统
└── 历史行程查询
```

**订单状态流转：**
```
[待确认] → [已确认] → [待上车] → [飞行中] → [已到达] → [待支付] → [已完成]
    │          │          │          │                        │
    └→[已取消] └→[已取消] └→[已取消] └→[异常处理]           └→[退款中]→[已退款]
```

### 4.3 航班调度服务 (Flight Service)
```
功能：
├── 航线管理（起降点、航路规划）
├── 智能调度算法（最优匹配）
├── 航班时刻表管理
├── 实时航班监控
├── 延误/取消管理
└── 应急预案处理
```

### 4.4 车辆管理服务 (Vehicle Service)
```
功能：
├── 车辆注册与信息管理
├── 车辆状态监控（电量、健康度）
├── 维保计划管理
├── 车辆调度与分配
├── 飞行日志记录
└── 车辆生命周期管理
```

### 4.5 空域管理服务 (Airspace Service)
```
功能：
├── 空域划分与管理
├── 飞行路径规划与冲突检测
├── 气象数据集成
├── 禁飞区管理
├── ADS-B 信号集成
└── UTM（无人机交通管理）对接
```

### 4.6 实时监控服务 (Monitoring Service)
```
功能：
├── 实时位置追踪（GPS + 北斗）
├── 车辆遥测数据采集
├── 异常告警（电量低、偏航、故障）
├── 飞行安全监控
├── 视频监控集成
└── 运营态势大屏
```

### 4.7 支付服务 (Payment Service)
```
功能：
├── 多种支付方式（微信/支付宝/银行卡）
├── 动态定价引擎
├── 优惠券与促销管理
├── 结算与对账
├── 发票管理
└── 飞行员收益结算
```

### 4.8 通知服务 (Notification Service)
```
功能：
├── 短信通知
├── 微信模板消息/订阅消息
├── APP 推送
├── 邮件通知
├── 系统消息
└── 告警通知（运维）
```

## 5. 非功能性需求

### 5.1 性能要求
| 指标 | 目标值 |
|------|--------|
| API 响应时间 | P99 < 200ms |
| 位置更新频率 | ≤ 1秒/次 |
| 并发用户数 | ≥ 10,000 |
| 系统可用性 | ≥ 99.99% |
| 数据持久化 | RPO = 0 (零数据丢失) |

### 5.2 安全要求
- JWT + OAuth 2.0 认证
- HTTPS 全链路加密
- 数据脱敏与隐私保护
- 操作审计日志
- 安全漏洞扫描与修复
- 飞行数据加密存储

### 5.3 可扩展性
- 微服务架构，服务独立扩缩容
- 数据库读写分离与分库分表
- CDN 静态资源加速
- 消息队列削峰填谷

## 6. 部署架构

### 6.1 开发环境
```
Docker Compose 本地开发环境
├── app-backend (Node.js)
├── app-admin (Vue 3 + Nginx)
├── app-mobile (Vue 3 + Nginx)
├── mysql (MySQL 8.0)
├── redis (Redis 6.x)
└── rabbitmq (RabbitMQ)
```

### 6.2 生产环境
```
Kubernetes 集群
├── Ingress Controller (Nginx)
├── Backend Pods (Node.js, HPA 自动扩缩容)
├── Frontend Pods (Nginx, 静态资源)
├── MySQL (主从复制)
├── Redis Cluster (哨兵模式)
├── RabbitMQ Cluster
├── Prometheus + Grafana (监控)
└── ELK Stack (日志)
```
