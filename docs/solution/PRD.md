# 飞行汽车运营平台 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
**飞行汽车运营平台** (Flying Car Operations Platform, FCOP)

### 1.2 产品愿景
构建安全、高效、智能的城市空中交通运营平台，为飞行汽车商业化运营提供一站式数字化解决方案，让空中出行触手可及。

### 1.3 产品目标
- 实现飞行汽车出行服务的全流程线上化管理
- 提供安全可靠的飞行调度与空域管理能力
- 打造极致的用户出行体验
- 建立高效的车辆运维管理体系
- 支撑运营决策的数据分析能力

## 2. 用户角色定义

### 2.1 乘客 (Passenger)
| 属性 | 描述 |
|------|------|
| 核心需求 | 快速、安全、舒适的空中出行 |
| 使用场景 | 通勤、机场接驳、商务出行、观光 |
| 使用设备 | 智能手机（微信小程序/公众号） |
| 关键动作 | 搜索航线→预订→支付→乘机→评价 |

### 2.2 飞行员 (Pilot)
| 属性 | 描述 |
|------|------|
| 核心需求 | 清晰的任务指派、安全的飞行支持 |
| 使用场景 | 接收调度指令、执行飞行任务 |
| 使用设备 | 专用平板终端/车载系统 |
| 关键动作 | 接单→准备→飞行→交付→记录 |

### 2.3 运营管理员 (Operations Manager)
| 属性 | 描述 |
|------|------|
| 核心需求 | 高效管理运营全流程，保障安全与效率 |
| 使用场景 | 调度管理、异常处理、数据分析 |
| 使用设备 | PC（管理后台）/大屏（监控中心） |
| 关键动作 | 调度→监控→处置→分析→优化 |

### 2.4 维保人员 (Maintenance Staff)
| 属性 | 描述 |
|------|------|
| 核心需求 | 精确的维保任务管理和车辆健康监控 |
| 使用场景 | 日常维护、故障排查、定期检修 |

## 3. 功能模块详细设计

### 3.1 乘客端功能

#### 3.1.1 用户注册与登录
- **微信一键登录**：获取微信 OpenID，一键注册登录
- **手机号注册**：短信验证码注册登录
- **实名认证**：身份证 + 人脸识别实名认证（飞行安全要求）
- **紧急联系人**：必须设置至少一位紧急联系人

#### 3.1.2 航线浏览与搜索
- **起降点查询**：基于地图展示所有可用起降点（Vertiport）
- **航线推荐**：根据用户位置推荐最近的起降点和热门航线
- **智能搜索**：支持按目的地、时间、价格搜索航线
- **航线详情**：展示飞行时间、距离、预估价格、可用车型

#### 3.1.3 行程预订
- **即时预订**：选择最近可用航班立即预订
- **预约预订**：选择未来 7 天内的航班时段预订
- **座位选择**：选择偏好座位（前排/后排/靠窗）
- **行李申报**：申报随身行李重量（安全要求）
- **特殊需求**：无障碍服务、儿童座椅等
- **同行乘客**：支持添加同行乘客信息

#### 3.1.4 订单管理
- **订单列表**：查看所有订单（待确认/进行中/已完成/已取消）
- **订单详情**：查看完整的订单信息、飞行路线、费用明细
- **订单跟踪**：实时追踪航班位置和预计到达时间
- **取消订单**：取消规则和退款政策说明
- **改签服务**：行程变更与差价处理

#### 3.1.5 支付
- **多种支付方式**：微信支付、支付宝、银行卡
- **费用明细**：基础票价 + 燃油费 + 保险费 + 服务费
- **优惠券**：新人券、折扣券、满减券
- **会员充值**：储值卡、月卡、年卡
- **发票申请**：电子发票自助申请

#### 3.1.6 行程评价
- **多维评价**：安全性、舒适度、准时性、服务态度
- **文字评价**：100 字以内的文字点评
- **图片上传**：最多上传 3 张图片
- **匿名评价**：支持匿名评价

#### 3.1.7 个人中心
- **个人信息管理**：修改头像、昵称、联系方式
- **常用地址管理**：保存常用起降点
- **飞行里程**：累计飞行里程和次数统计
- **会员等级**：根据消费和里程划分等级
- **消息中心**：系统通知、订单消息、活动推送
- **客服中心**：在线客服、电话客服、FAQ

### 3.2 飞行员端功能

#### 3.2.1 飞行员管理
- **注册审核**：提交飞行执照、体检证明等资质材料
- **排班管理**：查看和确认排班计划
- **状态切换**：上线/下线/休息状态管理
- **个人仪表盘**：当日任务、收益统计、评分

#### 3.2.2 任务管理
- **任务接收**：接收系统派发的飞行任务
- **任务详情**：乘客信息、航线信息、起降点位置
- **飞行前检查**：按检查清单完成飞行前准备
- **任务执行**：起飞确认、航行中状态更新、到达确认
- **异常上报**：故障、天气、乘客问题上报

#### 3.2.3 飞行辅助
- **导航地图**：3D 航线导航和空域信息
- **气象信息**：实时气象条件和预警
- **通信系统**：与调度中心语音/文字通信
- **检查清单**：标准化飞行前/飞行中/飞行后检查清单

#### 3.2.4 收益管理
- **收益明细**：每单收益、补贴、奖金明细
- **提现管理**：收益提现到银行卡
- **月度报表**：月度飞行数据和收益报表

### 3.3 管理后台功能

#### 3.3.1 仪表盘 (Dashboard)
- **运营概览**：今日订单数、收入、飞行次数、在线车辆数
- **实时态势**：地图上展示所有在飞、等待、维护中的车辆
- **趋势分析**：订单量、收入、用户增长等趋势图
- **告警中心**：系统异常、安全告警汇总

#### 3.3.2 订单管理
- **订单列表**：全部订单查询，支持多维度筛选
- **订单详情**：完整订单信息和操作记录
- **异常处理**：超时、投诉、纠纷处理
- **退款管理**：退款审核和处理
- **订单导出**：数据导出为 Excel

#### 3.3.3 航线管理
- **起降点管理**：添加/编辑/停用起降点（Vertiport）
- **航线配置**：配置航线的起降点、飞行路径、预估时间
- **时刻表管理**：设置航班时刻表和频次
- **定价策略**：设置基础价格、动态定价规则
- **航线分析**：航线利用率、准点率分析

#### 3.3.4 车辆管理
- **车辆信息**：车辆型号、注册号、容量、续航等基本信息
- **车辆状态**：实时状态监控（可用/飞行中/充电中/维护中）
- **电量管理**：电池电量监控和充电调度
- **维保管理**：维保计划、维修记录、配件管理
- **车辆调度**：手动/自动车辆调度

#### 3.3.5 飞行员管理
- **人员管理**：飞行员信息、资质、评分管理
- **排班管理**：排班计划制定和调整
- **绩效评估**：飞行时长、准时率、评分统计
- **培训管理**：培训记录和考核管理

#### 3.3.6 用户管理
- **用户列表**：全部用户查询和管理
- **用户详情**：用户画像、行程历史、消费记录
- **黑名单管理**：违规用户管理
- **VIP 管理**：VIP 用户等级和权益管理

#### 3.3.7 空域管理
- **空域地图**：3D 空域可视化展示
- **禁飞区管理**：设置和管理禁飞区域
- **飞行路径审核**：新航线路径的安全审核
- **冲突检测**：飞行路径冲突检测和预警
- **气象集成**：实时气象数据和飞行条件评估

#### 3.3.8 财务管理
- **收入统计**：日/周/月/年收入统计和趋势
- **成本分析**：运营成本、维保成本、人力成本分析
- **结算管理**：飞行员结算、合作方结算
- **发票管理**：发票开具和管理

#### 3.3.9 安全管理
- **安全事件**：安全事件记录和调查
- **飞行日志**：完整飞行日志查询
- **安全检查**：安全检查任务管理
- **合规报告**：监管合规报告生成

#### 3.3.10 系统管理
- **角色权限**：RBAC 角色权限配置
- **操作日志**：全部操作审计日志
- **系统配置**：全局参数配置
- **数据备份**：数据备份与恢复管理

### 3.4 监控大屏

#### 3.4.1 运营态势大屏
- **3D 地图展示**：全部飞行汽车实时位置
- **航班状态板**：当前航班状态汇总
- **关键指标**：实时订单数、在飞数量、候客数量
- **告警信息**：滚动展示最新告警

#### 3.4.2 安全监控大屏
- **飞行轨迹**：所有飞行中车辆的实时轨迹
- **异常预警**：偏航、低电量、超速等预警
- **天气状况**：实时天气和风速风向
- **应急联络**：一键呼叫应急联络人

## 4. 业务规则

### 4.1 预订规则
| 规则 | 描述 |
|------|------|
| 提前预订时间 | 至少提前 30 分钟预订 |
| 最长预约时间 | 提前 7 天预约 |
| 每人预订上限 | 同时最多 3 个未完成订单 |
| 实名要求 | 必须完成实名认证后方可预订 |
| 行李限制 | 随身行李不超过 10kg |

### 4.2 取消与退款规则
| 取消时间 | 退款比例 |
|----------|----------|
| 起飞前 2 小时以上 | 全额退款 |
| 起飞前 1-2 小时 | 退款 80% |
| 起飞前 30 分钟-1 小时 | 退款 50% |
| 起飞前 30 分钟内 | 不予退款 |
| 航班取消（平台原因） | 全额退款 + 补偿 |
| 航班取消（天气原因） | 全额退款 |

### 4.3 定价规则
- **基础票价** = 起步价 + (飞行距离 × 公里单价)
- **动态调价** = 基础票价 × 供需系数 (0.8 ~ 2.0)
- **时段加价** = 高峰时段加收 20%-50%
- **会员优惠** = 金卡 95 折，白金卡 9 折，钻石卡 85 折
- **保险费** = 固定 10 元/人/次
- **服务费** = 订单金额 × 5%

### 4.4 安全规则
- 能见度低于 1km 禁止飞行
- 风速超过 8 级禁止飞行
- 雷雨天气禁止飞行
- 车辆电量低于 30% 不接新单
- 飞行员连续飞行不超过 8 小时
- 每架次飞行前必须完成安全检查

## 5. 数据指标

### 5.1 核心业务指标
| 指标名称 | 定义 | 目标值 |
|----------|------|--------|
| 日活跃用户 (DAU) | 每日登录并浏览的用户数 | ≥ 5,000 |
| 日订单量 | 每日成功完成的订单数 | ≥ 500 |
| 订单完成率 | 成功完成 / 总订单 × 100% | ≥ 95% |
| 航班准时率 | 准时起飞 / 总航班 × 100% | ≥ 90% |
| 用户满意度 | 4 星及以上评价占比 | ≥ 90% |
| 车辆利用率 | 飞行时间 / 可用时间 × 100% | ≥ 60% |
| 客诉率 | 投诉订单 / 总订单 × 100% | ≤ 1% |

### 5.2 安全指标
| 指标名称 | 定义 | 目标值 |
|----------|------|--------|
| 安全事故率 | 安全事故 / 总飞行次数 | 0 |
| 飞行前检查完成率 | 完成检查 / 应检查 | 100% |
| 维保按时完成率 | 按计划完成 / 应完成 | ≥ 98% |
