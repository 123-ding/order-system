# 低空智联网安全可信中台 — 功能清单

> 版本：v1.0 | 日期：2026-03-16

---

## 一、设备接入管理

### 1.1 无人机接入管理
| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-UAV-01 | 多品牌无人机注册 | 支持大疆（DJI）、道通（Autel）、极飞、亿航、自研等品牌无人机的注册与接入 |
| F-UAV-02 | 通信协议选择 | 下拉框选取协议：MAVLINK、DJI SDK、自定义 TCP/UDP、MQTT、REST |
| F-UAV-03 | 连接参数配置 | 配置目标 IP、端口、账号/密钥等连接参数 |
| F-UAV-04 | 无人机状态实时监控 | 实时显示飞行状态、坐标、高度、电量、速度、航向 |
| F-UAV-05 | 无人机任务下发 | 通过中台向指定无人机下发航线任务、返航、悬停指令 |
| F-UAV-06 | 无人机分组管理 | 按区域、任务类型对无人机进行分组 |
| F-UAV-07 | 设备在线/离线检测 | 心跳检测，自动标记离线设备并告警 |
| F-UAV-08 | 无人机历史轨迹查询 | 按时间段查询和回放无人机历史飞行轨迹 |

### 1.2 探测设备接入管理
| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-DET-01 | 多品牌探测设备注册 | 支持雷达、光电吊舱、ADS-B、WiFi 频谱探测器等各品牌设备 |
| F-DET-02 | 通信协议选择 | 下拉框选取：TCP、UDP、串口(RS-232/RS-485)、ONVIF、自定义协议 |
| F-DET-03 | 连接参数配置 | 配置 IP、端口、用户名、密码、串口参数等 |
| F-DET-04 | 探测数据实时接收 | 接收并解析各品牌探测设备上报的目标数据（位置、高度、速度等） |
| F-DET-05 | 探测告警联动 | 当探测到非授权目标时，自动触发告警并联动相关设备 |
| F-DET-06 | 探测设备状态监控 | 实时显示设备在线状态、工作模式、信号强度 |
| F-DET-07 | 探测区域配置 | 配置探测设备的监控区域（电子围栏/扇形扫描范围） |

### 1.3 侦测设备接入管理
| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-SEN-01 | 多品牌侦测设备注册 | 支持射频频谱分析仪、无线电监测设备、图传侦测等品牌设备 |
| F-SEN-02 | 通信协议选择 | 下拉框选取：WebSocket、MQTT、HTTP/REST、自定义协议 |
| F-SEN-03 | 连接参数配置 | 配置 IP、端口、Topic、API Key 等 |
| F-SEN-04 | 侦测数据实时接收 | 实时接收射频信号数据、频谱数据、无人机信号特征 |
| F-SEN-05 | 目标身份识别 | 基于频谱特征库识别无人机品牌、型号 |
| F-SEN-06 | 侦测设备状态监控 | 显示设备在线状态、频段配置、扫描进度 |
| F-SEN-07 | 频谱数据可视化 | 提供频谱瀑布图、功率谱展示 |

### 1.4 反制设备接入管理
| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-CNT-01 | 多品牌反制设备注册 | 支持压制式干扰仪、导航欺骗设备、激光驱离等各品牌设备 |
| F-CNT-02 | 通信协议选择 | 下拉框选取：TCP、UDP、MQTT、串口、自定义协议 |
| F-CNT-03 | 连接参数配置 | 配置 IP、端口、设备 ID、控制密钥等 |
| F-CNT-04 | 反制指令下发 | 向指定反制设备下发启动/停止/调整参数等指令 |
| F-CNT-05 | 反制效果反馈 | 接收反制设备返回的执行结果和效果数据 |
| F-CNT-06 | 反制设备状态监控 | 显示设备在线状态、工作状态、能量/频段参数 |
| F-CNT-07 | 联动反制 | 与探测/侦测设备联动，自动触发或人工确认后启动反制 |
| F-CNT-08 | 反制操作日志 | 记录所有反制操作的时间、操作人、目标、结果 |

## 二、协议适配层

| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-PRO-01 | 协议模板管理 | 内置主流协议模板，支持自定义协议模板的增删改查 |
| F-PRO-02 | 报文解析配置 | 可视化配置设备数据报文的字段映射、解析规则 |
| F-PRO-03 | 协议转换网关 | 不同协议设备间的数据格式自动转换 |
| F-PRO-04 | 连接测试工具 | 一键测试设备连接是否正常 |
| F-PRO-05 | 通信日志查看 | 查看各设备的原始通信报文，支持搜索过滤 |

## 三、态势感知与可视化

| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-VIS-01 | GIS 地图展示 | 基于 GIS/地图展示所有设备及目标的实时位置 |
| F-VIS-02 | 目标轨迹展示 | 在地图上实时显示探测到的无人机目标轨迹 |
| F-VIS-03 | 设备状态总览 | Dashboard 展示各类设备在线数、告警数、任务数 |
| F-VIS-04 | 多窗口视频流 | 展示光电、热成像摄像头的实时视频流 |
| F-VIS-05 | 告警热力图 | 展示历史告警事件的地理分布热力图 |
| F-VIS-06 | 数据统计图表 | 按时间、区域、设备类型统计各类数据 |

## 四、告警与事件管理

| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-ALM-01 | 实时告警推送 | 系统告警通过 WebSocket 实时推送到前端页面 |
| F-ALM-02 | 告警级别分类 | 告警分为红色（紧急）、橙色（严重）、黄色（预警）三级 |
| F-ALM-03 | 告警确认与处置 | 操作人员可对告警进行确认、备注、关闭处理 |
| F-ALM-04 | 告警规则配置 | 自定义告警触发条件（如禁飞区闯入、信号异常等） |
| F-ALM-05 | 告警历史查询 | 按时间、类型、状态查询历史告警记录 |
| F-ALM-06 | 告警通知方式 | 支持短信、邮件、系统内通知等多种告警通知方式 |
| F-ALM-07 | 联动处置工作流 | 告警触发后按预设工作流自动通知相关人员并推荐处置方案 |

## 五、安全与可信管理

| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-SEC-01 | 设备身份认证 | 设备接入时进行证书/密钥双向认证 |
| F-SEC-02 | 通信加密 | 支持 TLS/SSL 加密通信，保障传输安全 |
| F-SEC-03 | 操作审计日志 | 记录所有用户操作行为，支持审计查询 |
| F-SEC-04 | 用户权限管理 | 基于角色的访问控制（RBAC），按角色分配功能权限 |
| F-SEC-05 | 无人机白名单 | 维护合法飞行无人机白名单，自动识别未授权设备 |
| F-SEC-06 | 禁飞区管理 | 配置禁飞区域，实时检测违规飞行并告警 |
| F-SEC-07 | 数据脱敏 | 敏感数据（如设备 ID、坐标等）在展示时支持脱敏处理 |

## 六、系统管理

| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-SYS-01 | 用户管理 | 用户的增删改查、角色分配、密码重置 |
| F-SYS-02 | 角色权限管理 | 角色的定义及菜单/功能权限配置 |
| F-SYS-03 | 系统参数配置 | 系统全局参数（超时时间、重试次数等）的配置 |
| F-SYS-04 | 数据字典管理 | 维护设备品牌、协议类型、告警类型等基础数据 |
| F-SYS-05 | 系统监控 | 展示服务器 CPU、内存、网络等运行状态 |
| F-SYS-06 | 日志管理 | 系统运行日志、操作日志的查看与导出 |
| F-SYS-07 | 数据备份与恢复 | 定期备份配置数据与历史数据，支持恢复 |

## 七、接口开放能力

| 编号 | 功能名称 | 说明 |
|------|----------|------|
| F-API-01 | 北向 REST API | 向上层管理系统开放标准 REST API |
