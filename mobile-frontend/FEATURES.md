## 📊 数据流

```
用户操作 → 组件事件 → Store 更新 → API 请求 → 响应处理 → UI 更新
```

**示例: 加入购物车流程**
1. 用户点击"加入购物车"按钮
2. 触发 `addToCart()` 方法
3. 调用 `cartStore.addToCart(dish, quantity)`
4. Store 更新本地状态
5. 保存到 localStorage
6. Toast 提示成功
7. 购物车图标更新徽标
